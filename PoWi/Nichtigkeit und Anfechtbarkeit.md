# Aufgabenlösung

| Fall                     | gültig | nichtig | anfechtbar | BGB §§                   | Begründung                                                                                                                                                                                                                                                                               |
| ------------------------ | ------ | ------- | ---------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1** Ü-Eier             |        | X       |            | 104 Nr. 1, 105 I         | Felix (6) ist geschäftsunfähig, also ist seine Willenserklärung nichtig. Geld und Ü-Eier gehen zurück. Die schon gegessenen Eier muss er nicht ersetzen.                                                                                                                                 |
| **2** Freibier           |        | X       |            | 105 II                   | Kai hat im Vollrausch erklärt („völlig betrunken“), also bei einer vorübergehenden Störung der Geistestätigkeit. Die WE ist nichtig, die 128 € schuldet er nicht. Den Vollrausch muss allerdings Kai beweisen.                                                                           |
| **3** Gerichtsvollzieher |        | X       |            | 117 I                    | Die Schenkung war ein Scheingeschäft. Beide wollten die Wirkung nicht, also ist sie nichtig. Klaus bleibt Eigentümer und kann die Münzsammlung zurückverlangen (§ 985).                                                                                                                  |
| **4** April, April       |        | X       |            | 118 (122 II)             | Die Verkäuferin hat zum Scherz erklärt und erwartet, dass der Scherz erkannt wird (Scherzgeschäft). Kein Vertrag zu 1 €. Schadensersatz bekommt Walter nicht, weil er den Scherz hätte erkennen müssen (§ 122 II).                                                                       |
| **5** Seelenkäufer       |        | X       |            | 138 I                    | Ein Religionswechsel gegen Geld verstößt gegen die guten Sitten (Glaubensfreiheit, Art. 4 GG). Der Vertrag ist nichtig.                                                                                                                                                                  |
| **6** Dieb               |        | X       |            | 134, 138 I               | Einbruch und Diebstahl sind strafbar (gesetzliches Verbot), dazu sittenwidrig. Der Vertrag ist nichtig. Gomm hat weder einen Anspruch auf 20.000 € noch auf 10.000 €.                                                                                                                    |
| **7** Standort           |        | X       | X          | 123 I, 124 / 125, 311b I | Die Mieteinnahmen wurden zugesichert, obwohl die Wohnungen leer stehen. Das ist arglistige Täuschung, also anfechtbar (Frist 1 Jahr ab Entdeckung). Außerdem ist der Vertrag noch gar nicht notariell beurkundet, also bis dahin formnichtig. Wagner muss ihn so oder so nicht erfüllen. |
| **8** Babysitting        | (X)    |         |            | 106, 107, 108 I          | Nadine (14) ist beschränkt geschäftsfähig. Der Vertrag ist schwebend unwirksam, bis die Eltern zustimmen. Genehmigen sie, ist er gültig und Scholl muss 32 € zahlen. 8 €/Std. ist nicht sittenwidrig überhöht.                                                                           |
| **9** Kassiererin        |        |         | X          | 119 II, 121              | Vorstrafen wegen Unterschlagung sind bei einer Kassiererin eine verkehrswesentliche Eigenschaft. Der Marktleiter kann wegen Eigenschaftsirrtums anfechten, und zwar unverzüglich. Hat sie auf Nachfrage gelogen, gilt § 123.                                                             |
| **10** Zeugnis           | X      |         |            | –                        | Dass Link sich in Finks Fleiß geirrt hat, ist nur ein unbeachtlicher Motivirrtum. Der Vertrag bleibt gültig, Link kann nur kündigen. (Wären die Zeugnisse gefälscht, könnte er nach § 123 anfechten.)                                                                                    |
| **11** Bestell-Nr.       |        |         | X          | 119 I, 121, 122          | Ernle hat sich verschrieben (Erklärungsirrtum). Er kann unverzüglich anfechten, muss aber den Vertrauensschaden ersetzen, z. B. die Versandkosten.                                                                                                                                       |
| **12** Sohn              |        |         | X          | 120, 121, 122            | Wolfgang war nur Bote und hat die Erklärung falsch übermittelt. Der Vater kann anfechten wie bei § 119. (Am Rand: Tabak darf an Kinder gar nicht verkauft werden, § 10 JuSchG.)                                                                                                          |
| **13** Logieren          |        |         | X          | 119 I, 121, 122          | Protzig hat sich über die Bedeutung von „logieren“ (übernachten) geirrt (Inhaltsirrtum). Er kann anfechten, schuldet dem Hotel aber den Vertrauensschaden.                                                                                                                               |
| **14** Standuhr          |        |         | X          | 123 I, 124               | Helmut hat mit Bloßstellen gedroht, um die Uhr zu bekommen. Das ist eine widerrechtliche Drohung. Ralf kann anfechten, Frist 1 Jahr ab Ende der Zwangslage.                                                                                                                              |
| **15** Teppich           |        |         | X          | 123 I, 124               | Hubert hat das Gefälligkeitsgutachten selbst veranlasst und Maike damit getäuscht. Der Händler ist keine „dritte Person“ im Sinne von § 123 II. Maike kann anfechten, Frist 1 Jahr ab Entdeckung.                                                                                        |
